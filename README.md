# SlideScore AI

SlideScore AI is a React/Vite frontend with an Express API and MongoDB persistence.
Authentication and presentation reports are stored by the backend; analysis scores
are currently generated by the frontend's mock scoring engine.

## Run locally

Requirements: Node.js and MongoDB (local or hosted).

1. Configure and start the API:

   ```powershell
   cd backend
   Copy-Item .env.example .env
   npm install
   npm run dev
   ```

   Set `JWT_SECRET` to a long, random value before using real accounts. Configure
   `MONGODB_URI` for your MongoDB instance and `CLIENT_ORIGIN` for the frontend URL.

2. In a second terminal, start the frontend:

   ```powershell
   Copy-Item .env.example .env
   npm install
   npm run dev
   ```

   Vite proxies `/api` requests to `http://localhost:5000` by default. Set
   `VITE_API_URL` if the API is hosted at another URL. In production, configure
   the web server to proxy `/api` to the backend.

## API

- `POST /api/auth/register`, `POST /api/auth/login`
- `GET /api/auth/me`, `PATCH /api/auth/profile`, `POST /api/auth/logout`
- `GET /api/presentations`, `POST /api/presentations`
- `GET /api/presentations/:id`, `DELETE /api/presentations/:id`
- `GET /api/health`

Authenticated endpoints expect `Authorization: Bearer <token>`. Each account can
only access its own analyses.
